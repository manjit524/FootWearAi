REST API Reference

Integrate FootwearAI classification and visual matching into e-commerce checkout, mobile apps, or catalog crawlers.

POST /predict -- MULTIPART OR BASE64

Accepts multipart image upload or base64 JSON payload. Returns classified style, confidence score, detailed style encyclopedia notes, and multi-portal exact shoe match search queries.

EXAMPLE CURL:
curl -X POST \
  -F "image=@shoe.jpg" \
  http://127.0.0.1:5000/predict
PYTHON SDK:
import requests

url = "http://127.0.0.1:5000/predict"
with open("shoe.jpg", "rb") as f:
    r = requests.post(url, files={"image": f})
res = r.json()
print(res["category_name"], res["confidence"])
POST /api/exact-match -- DEEP EMBEDDING QUERY

Takes an image and computes a 1280-D normalized vector against our catalog index. Returns cosine similarity scores and prioritized deep-links across Amazon, Myntra, Flipkart, AJIO, and Google Lens.

GET /api/info -- METADATA

Returns runtime system status, model input dimensions, and all indexed footwear category keys.
